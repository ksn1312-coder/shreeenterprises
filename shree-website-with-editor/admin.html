Connect to GitHub

Publishing saves your changes straight into the website's GitHub repository. GitHub Pages then updates the live site in about a minute. You only need to do this once on each computer.

How to get a token: on GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access pick only this website's repository, and under Permissions → Contents choose Read and write. Copy the token and paste it above. It is stored only in this browser.
